# Birthday Countdown 🎉

A simple and clean **static website** that displays a **countdown timer** to an upcoming birthday. The timer updates in real time and shows the remaining **days, hours, minutes, and seconds** until the special day.

## 🚀 Features

- Real-time countdown timer
- Simple & responsive UI
- Works as a fully static site (no backend required)

## 📅 Description

The project calculates and displays the **time left until the next birthday** based on today's date.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## 📂 Project Setup

Just open the `index.html` file in your browser — no additional setup required.
